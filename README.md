# mobile_exam

This is the mobile app made by Edward Daniel Baldeviano, as part of the technical examination for the role of Frontend Developer at Hitachi Digital Payment Solutions Philippines, Inc.

## Technologies Used

This project is made using Flutter.

## How to Run

1. Make sure to have Flutter SDK installed on your device.
2. Fetch this repository to your device, then open it on your desired IDE. For reference, please refer to [Flutter's official documentation](https://flutter-website-staging.firebaseapp.com/using-ide/]).
3. On your local repository, apply the necessary setup to develop this project.
4. To test out API calls which are limited to CORS issues, you can apply this [temporary fix](https://corsfix.com/blog/fix-cors-error-flutter-web#temporary-solution).
5. Follow your native IDE's instructions on how to run a Flutter project.

For more details on Flutter development, please go to the [online documentation](https://docs.flutter.dev/), which offers tutorials, samples, guidance on mobile development, and a full API reference.
